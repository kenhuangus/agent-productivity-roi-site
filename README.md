## Abstract

This presentation delivers an enterprise framework to maximize AI workforce productivity and improve return on investment (ROI) across agentic deployments. Part 1 classifies IT systems into four investment buckets so capital follows productivity and value acquisition. Part 2 maps CSA AI Organizational Responsibility white papers, MAESTRO, AIVSS, CSA AICM, and the CSA Agentic AI Red Teaming Guide onto NIST AI RMF Govern / Map / Measure / Manage (with EU AI Act risk tiers as policy context). Part 3 applies seven tactical controls—autonomy bounds, IBAC, memory hygiene, observability, runtime steering, ROI evaluation, and model economics (routing + caching)—to raise productivity while protecting unit economics.
