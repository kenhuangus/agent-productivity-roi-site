Framework Overview

Three Parts: Value · Risk · Tactical ROI Controls

Enterprise Agentic AI ROI fails when teams skip prioritization, skip risk governance, or skip engineering controls. This deck sequences all three.

Agenda What Leaders Must Decide in Order

  • • Part 1 — Business value: classify every IT system into one of four Agentic AI investment buckets.
  • • Part 2 — Risk management: NIST AI RMF, EU AI Act, MAESTRO, AIVSS, CSA Agent Red Team, AICM.
  • • Part 3 — Seven tactical controls that raise productivity while protecting unit economics.
Part 1 · Business Value & Productivity

Four IT System Buckets for Agentic AI Investment

Not every system should become agentic. Portfolio ROI depends on putting each system in the right bucket before spending on models, harnesses, or replatforming.

Investment Logic Decide Before You Build Agents

  • • Bucket 1–2 protect spend: leave stable systems alone, or add agents only where productivity and value acquisition clearly improve.
  • • Bucket 3 concentrates capital: re-platform only when legacy architecture blocks Agentic productivity and ROI.
  • • Bucket 4 is greenfield: build new capabilities as Agentic AI–native from day one.
Part 2 · Risk Management · Policy Layer

Policy Anchors: NIST AI RMF & EU AI Act

Productivity gains evaporate when agents create regulatory, liability, or trust failures. Start risk management with recognized policy frameworks.

Policy How Policy Protects ROI

  • • NIST AI RMF: map Govern / Map / Measure / Manage to agent lifecycle gates so risk work is continuous, not a one-time audit.
  • • EU AI Act: classify agent use-cases by risk tier; high-risk systems get documented controls before production spend scales.
  • • ROI link: early policy gating prevents costly rework, incident response, and forced shutdowns after deployment.
Part 2 · Risk Management · Operational Stack

Operational Stack: MAESTRO · AIVSS · CSA

Policy alone is not enough. Agentic systems need threat modeling, vulnerability scoring, adversarial testing, and management controls that executives can run.

Toolkit Four Controls, Three Executive Moves

  • • MAESTRO: threat-model agent architectures (tools, memory, multi-agent paths) before expanding autonomy.
  • • AIVSS: score AI / agent vulnerabilities so remediation spend follows severity, not anecdote.
  • • CSA Agent AI Red Teaming + AICM: adversarially test agents, then manage residual risk with CSA AI Controls Matrix practices.
Part 3 · Tactical Controls

Seven Tactical Controls That Improve ROI

Once investment buckets and risk governance are set, these seven engineering controls convert agent autonomy into measurable productivity and lower unit cost.

Controls What Each Control Buys You

  • • Safety & scope: Autonomy bounds, Intent control (IBAC), and Memory hygiene stop waste and blast-radius loss.
  • • Runtime discipline: Observability and Steering catch drift and loops before budgets burn.
  • • Economics: Evaluation metrics plus Model Economics (routing + caching) prove and compound ROI.
Part 3 · Control 1

Autonomy Bounds & Tool Governance

Match task complexity to explicit Levels of Autonomy (LoA) and tool allowlists so agents raise velocity without unbounded spend or uncontrolled writes.

LoA Three ROI Rules for Autonomy

  • • Tier autonomy: LoA 0–1 for read/draft; LoA 2–3 for sandboxed or supervised write; LoA 4 only with hard kill switches.
  • • Least-privilege tools: strip shell and production write paths until the task and CapToken justify them.
  • • Spend velocity caps: rate-limit tool calls and task budgets to stop infinite retry loops.
Part 3 · Control 2

Intent-Based Access Control (IBAC)

RBAC fails for agents. Ground fuzzy prompts in a domain ontology and issue single-use CapTokens so execution follows verified intent, not ambient privilege.

IBAC Three Points That Protect ROI

  • • Confused Deputy: over-privileged agents execute injected goals; role grants alone cannot stop it.
  • • Ontology + Intent AST: resolve language into explicit entities, actions, and invariants before tools run.
  • • CapTokens: ephemeral, single-use credentials shrink blast radius and financial loss.
Part 3 · Control 3

Memory Hygiene & Context for Token ROI

Context bloat is the primary driver of runaway token cost and reasoning degradation. A three-tier memory model recovers productivity and margin.

Memory Three-Tier Discipline

  • • Tier 1 ephemeral: scratchpads and subagent worktrees zeroized at task end.
  • • Tier 2 quarantine: provenance-tagged buffer with strict TTL before promotion.
  • • Tier 3 verified long-term: signed immutable rules only — target ~65% token savings.
Part 3 · Control 4

Trajectory Observability & Drift Detection

You cannot manage ROI you cannot see. OTel GenAI tracing exposes plan drift, token waste, and tool loops while the run is still recoverable.

OTel Three Observability Must-Haves

  • • Thought → Plan → Tool → Observation DAG for every multi-turn agent run.
  • • Latency and token breakdown per step to find the expensive bottlenecks.
  • • Drift and loop scoring to halt retry oscillations before budget hemorrhage.
Part 3 · Control 5

Active Runtime Steering & Control Gateway

Passive logs arrive after the money is gone. Deterministic Pre/PostToolUse interceptors approve, steer, sandbox, or kill in real time.

Steering Three Gateway Actions That Save ROI

  • • PreToolUse: schema, budget, and CapToken checks before any side effect.
  • • PostToolUse: scrub injection, secrets, and unsafe payloads from tool output.
  • • Decision primitives: APPROVE · STEER · SANDBOX · KILL without full restart waste.
Part 3 · Control 6

Evaluation & Enterprise ROI Benchmarks

Replace vanity LLM scores with engineering ROI metrics executives can fund: completion, cost per success, and human effort reclaimed.

Metrics Three Metrics That Matter

  • • TCR — Task Completion Rate without human repair (target ≥90%).
  • • CPST — Cost Per Successful Task (LLM + compute ÷ verified deliverables).
  • • HER — Human Effort Reduction net of oversight time; pair with continuous red-team regression.
Part 3 · Control 7

Model Economics: Routing & Prompt Caching

Frontier models for every sub-task destroy unit economics. Cascaded routing plus prompt-cache TTL discipline routinely cuts inference cost 70–85%.

Economics Three Levers on Unit Cost

  • • Tiered routing: local/edge → open-weights → frontier only for hard reasoning.
  • • Complexity classifier: send ~65% of sub-tasks away from frontier prices.
  • • Prompt cache: static prefixes + sliding TTL (e.g. Claude 5-min) for ~90% input discount and faster TTFT.
Executive Synthesis

Three Moves That Compound Agentic ROI

Productivity and ROI come from portfolio selection, risk governance, and tactical engineering — not from buying a larger model alone.

Takeaways Remember These Three

  • • Part 1: Put every IT system in one of four buckets before funding agents.
  • • Part 2: Run NIST AI RMF + EU AI Act with MAESTRO, AIVSS, CSA Red Team, and AICM.
  • • Part 3: Enforce the seven controls — autonomy, IBAC, memory, observability, steering, eval, model economics.
