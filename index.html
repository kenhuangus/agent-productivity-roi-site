Part 3 · Controls

Seven Controls for ROI

Convert autonomy into productivity and lower unit cost.

Controls What each buys

  • • Scope: Autonomy, IBAC, Memory.
  • • Runtime: Observability, Steering.
  • • Economics: Eval + routing/cache.
Control 1

Autonomy & Tool Bounds

Match LoA and tool allowlists to the task.

LoA Three rules

  • • LoA 0–1 read/draft; 2–3 sandbox/supervise; 4 with kill switches.
  • • Least-privilege tools until CapToken justifies more.
  • • Cap tool rate and spend to stop retry loops.
Control 2

Intent-Based Access (IBAC)

Bound tools to verified intent, not ambient roles.

IBAC Three points

  • • Confused Deputy: injection + broad roles.
  • • Ontology + Intent AST before tools run.
  • • Single-use CapTokens shrink blast radius.
Control 3

Memory Hygiene

Context bloat drives token cost and weak reasoning.

Memory Three tiers

  • • Tier 1 ephemeral — zeroize at end.
  • • Tier 2 quarantine + TTL.
  • • Tier 3 signed rules only (~65% token cut).
Control 4

Trajectory Observability

OTel catches drift and waste while the run is recoverable.

OTel Three must-haves

  • • Thought → Plan → Tool → Observation DAG.
  • • Per-step latency and token cost.
  • • Halt after 3 identical tool failures.
Control 5

Runtime Steering

Intercept before side effects—not after the bill.

Steering Three actions

  • • PreToolUse: schema, budget, CapToken.
  • • PostToolUse: scrub secrets and injection.
  • • APPROVE · STEER · SANDBOX · KILL.
Control 6

ROI Benchmarks

Fund TCR, CPST, HER—not vanity LLM scores.

Metrics Three metrics

  • • TCR ≥90% without human repair.
  • • CPST = spend ÷ verified deliverables.
  • • HER = hours saved − oversight; keep red-team gates.
Control 7

Model Economics

Routing + cache cuts inference cost 70–85%.

Economics Three levers

  • • Local → open-weights → frontier only when hard.
  • • ~65% of sub-tasks off frontier price.
  • • Prompt cache + sliding TTL (~90% input discount).

Three Moves for Agentic ROI

Buckets + NIST map + seven controls beat a bigger model alone.
